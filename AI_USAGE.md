# AI Usage Documentation

## AI Tools Used

- ChatGPT

## How AI Was Used

I used AI as a support tool during the development of this project. AI helped me with:

- clarifying how CRUD works
- understanding how Flask connects to MySQL
- debugging errors in Python, Flask, and MySQL
- reviewing SQL queries
- improving HTML/CSS structure and styling
- organizing the project into smaller steps

## Examples of Helpful Prompts

Some of the prompts I used included:

- Help me connect Flask to MySQL.
- Help me understand this code before I use it.
- Help me create routes for Companies, Jobs, Applications, and Contacts.
- Help me use the JSON requirements field for a Job Match feature.

## How I Used the AI Output

I did not use AI output without checking it. I reviewed the suggestions, tested the code, and adjusted it to match my database structure and the project requirements. AI was most useful for guidance, debugging, and explaining code that I was building and testing in my own environment.

## Changes I Made During Development

During the project, I made changes based on testing and project needs, including:

- updating database credentials to match my MySQL setup
- checking that routes matched my templates
- verifying the schema before finalizing `schema.sql`
- adjusting forms, links, and queries until the application worked correctly
- improving the interface after the core functionality was complete

## What I Learned

This project helped me learn how to:

- build a Flask application connected to MySQL
- create CRUD routes and templates
- work with foreign keys between tables
- use JSON data in MySQL
- implement a Job Match feature with skill comparison
- use AI more effectively by asking focused questions and testing everything carefully

## Reflection

AI was used as a learning and support tool throughout the project. It helped me understand concepts, debug issues, and improve the application, but I still had to test the project, verify results, and make sure everything worked correctly in my own setup.
